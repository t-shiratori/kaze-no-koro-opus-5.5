## まず全体像だけ知りたいとき

- このアプリは **画像も 3D モデルも一切使わず**、空・雲・海・島・機体・船・鳥をすべてコードで生成しています。
- 依存ライブラリは `three`（three.js）だけです。描画の大部分は three.js の上に自作した GLSL シェーダとマルチパスのパイプラインで行っています。
- 1 フレームは「環境の事前計算（空の LUT・雲の影・FFT）→ シーン → 半解像度の雲 → 合成 → ブルーム → 仕上げ」の順で描かれます（[3 章](03-render-pipeline.md)）。
- 光・風・雲・時間は `src/render/globals.ts` の共有ユニフォーム `G` を通して **すべてのシェーダで同じ値** を参照するので、雲の影が海にも島にも鳥にも同時に落ち、風が雲にも波にも木にも同じ向きで効きます（[2 章](02-architecture.md)）。

## 図版について

`images/` の画像は 2 種類あります。

- **スクリーンショット・中間バッファ**（`*.jpg`）：開発サーバーで実際に動かした画面と、パイプラインのレンダーターゲットを読み出して可視化したものです。
- **図解**（`*.svg`）：仕組みの説明用。曲線の図（時間の流れ、雲の形、海のメッシュなど）は、ソースコードと同じ式から描いています。

フローやシーケンスは Mermaid で書いています（GitHub や VS Code のプレビューでそのまま図になります）。
