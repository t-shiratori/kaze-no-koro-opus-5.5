# 風の航路

架空の地中海の群島の上を、古い飛行艇がただ静かに飛び続ける。ブラウザで動くリアルタイム 3D の「動く風景画」です。
操作は要りません。旅の行き先も、雲も、光も、自動で移ろいます。

## 起動

```bash
mise install        # Node.js 24 LTS と pnpm
pnpm install
pnpm dev            # http://localhost:5287
```

| コマンド            | 内容                    |
| ------------------- | ----------------------- |
| `pnpm dev`          | 開発サーバー            |
| `pnpm build`        | 型チェック + 本番ビルド |
| `pnpm preview`      | ビルド結果の確認        |
| `pnpm lint`         | Oxlint                  |
| `pnpm format`       | Oxfmt で整形            |
| `pnpm format:check` | 整形の確認              |

WebGL2 に対応したブラウザ（最近の Chrome / Edge / Safari / Firefox）で動きます。

## 操作（すべて任意）

- マウスを動かすと左下に控えめな操作が現れ、しばらくすると消えます
- `移ろい / 朝 / 昼 / 光芒 / 夕 / 夜`（キー `0`〜`5`）: 時間帯と空模様。`移ろい`は一日がゆっくり巡ります（約 18 分で一日）。`光芒`は低い朝日と切れ間のある雲の天井で、雲間から海へ落ちる光の筋を見せるモードです
- `標準 / シネマ`（キー `C`）: カメラ。`シネマ`は映画のようにカットを切り替えるオートディレクション（シネスコの黒帯付き）。フライバイ、望遠、並走、正面、海面すれすれ、俯瞰、真上、周回、コックピット、翼端、尾翼、島を背景にした定点、太陽方向を、周囲の状況から選んで数秒ごとに切り替えます
- ドラッグで見回し、ホイールで距離。手を離すと数秒で映画的なカメラに戻ります
- カメラアイコン（キー `P`）: フォトモード。世界が一時停止し、ドラッグで機体の周りを回り込み、ホイールで距離、スライダーで広角〜望遠を選べます。止めたまま時間帯のボタンで光だけ変えることもできます。`撮影`（キー `Space`）でその画面を PNG で保存、`終了`（`P` / `Esc`）で飛行に戻ります
- `F` 全画面、`H` 操作の表示/非表示

開発用に URL パラメーター `?t=17.5`（開始時刻）と `?instant`（フェードインを省略）があります。

## 世界のつくり

すべて手続き的に生成しています。画像や 3D モデルのアセットは使っていません。

- **空** — レイリー散乱・ミー散乱・オゾン吸収による単一散乱の空を、毎フレーム小さな sky-view LUT に焼き込みます。空、海の映り込み、空気遠近、環境光（PMREM）がすべてこの LUT を共有します。夕方の太陽にはわずかに金色を足しています。
- **雲** — 半解像度のボリュームレイマーチ。天気マップ（被覆・地域の曇り具合・雨）と 3D の Perlin-Worley ノイズを起動時に GPU で生成します。雲の高さは被覆の余裕に比例するので、小さな綿雲から巨大な積雲の塔まで自然に混ざります。二重ローブの位相関数、多重散乱の近似、時間方向の再投影で滑らかにしています。
- **雲の中を飛ぶ** — 自動操縦が 2〜4 分に一度ほど前方の濃い雲を選び、そこを突き抜けるように高度と進路を合わせます。雲の中ではカメラが機体に寄り、白い霧の向こうから景色が現れます。
- **光芒モード** — 切れ間のある層積雲の天井が現れ、雲の下の空気に差し込む日差しを体積的に積分して光の筋を描きます。カメラは太陽の方を向く構図を多く選びます。`移ろい`でも十数分に一度、同じ空模様が自然に訪れます。
- **雲の影と光芒** — 太陽方向に雲を透かした透過率マップを毎フレーム作り、海・島・機体・鳥の直射光に掛けます。同じマップを視線上で積分して、雲の切れ間から落ちる光芒をつくります。光芒の強さはゆっくり変化し、ときどきだけ強く現れます。
- **雨** — 雨がちな地域の雲の下に、灰色の雨のカーテンが遠くに見えます。
- **海** — 放射状グリッドのゲルストナー波（うねり）＋風浪とさざ波の FFT 海洋（波のスペクトルを毎フレーム GPU で逆 FFT。大きさと向きの異なる3段のカスケードで繰り返し模様を出さない）。画素より細かい波はミップマップと反射のアンチエイリアスでなめらかに消える。フレネル反射、GGX の太陽/月のきらめき、距離に応じた粗さ（遠くでは光の道になる）、風の突風で色が変わる水面、雲の反射、船の航跡（ケルビン波）、白波。島の高さマップから水深を得て、浅瀬の砂地・海草・コースティクス・打ち寄せる泡を描きます。
- **島** — 3.2 km 四方のセルごとに決定論的に島を置き、Web Worker でメッシュ化します。岩礁、白い断崖、緑の山、細長い島、群島、入り江の村、灯台の小島、古い塔の島、松の島、浅瀬の砂の島の 10 種。植生のモザイク、石灰岩の露頭、浜辺、傘松・糸杉・オリーブ、白い家と瓦屋根（夜は窓に灯り）、桟橋と舫われた小舟、灯台（夜は回転する光）、廃墟の塔。
- **生命** — ヨット、漁船、貨物船、フェリーが島を避けながら行き交い、夜は航海灯と窓明かりを灯します。断崖ではカモメが旋回し、ときどき群れが機体の前を横切り、一羽だけ遠くを滑空していることもあります。数分に一度、遠くを別の飛行機が飛んでいきます。
- **風** — ひとつの風が、雲の流れ、海のさざ波と突風、木々の揺れ、鳥の漂い、機体の揺れ、帆の向きに共通して効いています。
- **飛行** — 自動操縦は近くの島から興味深いものを選び、その海岸沿いを通り抜けるように飛びます。高度は海面すれすれ・中高度・雲底付近を行き来し、雲の中を抜けることもあります。旋回は協調旋回、気流でわずかに揺れます。
- **カメラ** — 追従、低空、島を背景にした横位置、見上げる雲、前方からの振り返り、高い俯瞰、ゆっくりした周回などの構図を、周囲の状況から選び、数秒かけて気づかないほど滑らかに移ります。
- **画づくり** — HDR（MSAA）で描き、空気遠近と雲を合成、ブルーム、ACES 系トーンマップ、時間帯ごとのグレーディング。フレーム時間に応じて解像度を自動調整します。

## 構成

```
src/
  main.ts                 起動とフレームループ
  core/                   ノイズ、補間、スプリング
  env/                    時刻、大気（CPU 側）、天気マップ
  flight/                 自動操縦、カメラディレクター
  render/                 パイプライン、共有ユニフォーム、マテリアル拡張、GLSL
  world/                  海、島（生成・Worker・管理）、船、鳥、機体、夜の灯り
  ui/                     控えめな操作 UI
```

依存は `three` のみ（開発時は `vite`、`typescript`、`oxlint`、`oxfmt`）。
